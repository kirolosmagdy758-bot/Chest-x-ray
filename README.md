# Chest-x-ray
Deep Learning-Based Classification of COVID-19, Lung Opacity, Normal, and Viral Pneumonia Using Chest X-Ray Images
# Chest X-ray Disease Classification Using Custom CNN

This project presents a custom Convolutional Neural Network (CNN) model for classifying chest X-ray images into four categories: COVID-19, Lung Opacity, Normal, and Viral Pneumonia.

## Dataset
The dataset used in this project is the Balanced Augmented COVID Chest X-Ray Dataset from Kaggle.

## Model
The model is a custom CNN architecture trained on grayscale chest X-ray images resized to 150×150 pixels.

## Classes
- COVID-19
- Lung Opacity
- Normal
- Viral Pneumonia

## Results
The model achieved an overall accuracy of 97% with a weighted average F1-score of 0.98.

## How to Run
Open the notebook file `chest-x-ray.ipynb` and run the cells in order.
